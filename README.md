# 🏠 Prime Design | Móveis Planejados

✨ **Prime Design** é um projeto de website moderno e responsivo desenvolvido para representar uma empresa fictícia de móveis planejados premium.

O objetivo do projeto foi criar uma experiência visual sofisticada, valorizando os ambientes, os projetos realizados e a identidade da marca. O site foi desenvolvido com foco em **design, responsividade, animações e experiência do usuário**.

---

🔗 **Acesse o projeto online:**  
[Prime Design - Website](https://prime-design.vercel.app/)

# ✨ Funcionalidades

O projeto foi desenvolvido pensando em criar uma navegação moderna e uma experiência visual agradável para o usuário.

### 🖥️ Interface Moderna

Uma interface premium inspirada em sites de arquitetura e design de interiores, utilizando uma combinação de:

- Tipografia elegante
- Layout minimalista
- Paleta de cores sofisticada
- Imagens de ambientes planejados
- Elementos visuais interativos

### 🖼️ Portfólio Interativo

A seção de projetos permite explorar diferentes ambientes desenvolvidos pela empresa.

✨ **Recursos implementados:**

- Carrossel automático de projetos
- Botões de navegação
- Navegação por swipe em dispositivos móveis
- Filtros para organização dos ambientes
- Efeito de zoom nas imagens
- Overlay interativo ao passar o mouse
- Visualização ampliada dos projetos

### 🎞️ Animações e Experiência do Usuário

Para tornar a navegação mais dinâmica, foram adicionadas diversas animações ao projeto:

- Scroll reveal nas seções
- Animação de carregamento inicial
- Efeito de zoom na imagem principal
- Animações em botões e cards
- Contadores animados
- Cursor personalizado para desktop
- Transições suaves entre elementos

### 📱 Design Responsivo

O website foi adaptado para diferentes tamanhos de tela.

💻 **Desktop**  
📱 **Smartphones**  
📲 **Tablets**

O layout se reorganiza automaticamente para proporcionar uma boa experiência independentemente do dispositivo utilizado.

### 📲 Contato Integrado

O botão de orçamento direciona o usuário diretamente para o **WhatsApp**, facilitando o contato com a empresa.

# 🚀 Como Executar o Projeto

Para visualizar o projeto localmente:

### 1️⃣ Clone este repositório

```bash
git clone https://github.com/RickFrec/prime-design.git
```

### 2️⃣ Acesse a pasta do projeto

```bash
cd prime-design
```

### 3️⃣ Abra o projeto

Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão **Live Server** no Visual Studio Code.

# 🎯 Objetivo do Projeto

Este projeto foi desenvolvido como parte do meu processo de aprendizado em **Desenvolvimento Web Front-End** e também para compor meu portfólio de projetos.

Durante o desenvolvimento, foram aplicados conceitos importantes como:

- Estruturação de páginas com HTML
- Estilização avançada com CSS
- Responsividade
- Manipulação do DOM com JavaScript
- Eventos e interações
- Animações
- Carrosséis
- Filtros de projetos
- Galeria interativa de imagens
- Git e GitHub
- Deploy de aplicações web

Além do aprendizado técnico, o projeto também simula um cenário real de desenvolvimento de um website para uma empresa.
